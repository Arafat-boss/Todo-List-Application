# Todo List Application 📱

A modern, clean, and user-friendly Todo List mobile application built with **React Native**, **Expo**, and **TypeScript**.

---

## ✨ Features

- **Add New Tasks:** Quickly add daily tasks and todos.
- **Mark as Completed:** Tap on any task to mark it as done or undo it with a clean visual checkmark.
- **Delete Tasks:** Easily remove tasks you no longer need.
- **Remaining Task Counter:** See exactly how many tasks are pending at a glance.
- **Progress Tracking:** Interactive progress bar showing your completion percentage.
- **Filter Tasks:** Filter view by **All**, **Active**, and **Completed** tasks.
- **Cross-Platform:** Runs smoothly on Android, iOS, and Web browsers.
- **Modern UI:** Clean card layout with soft shadows and smooth animations.

---

## 🚀 How to Run the Project

Follow these simple steps to run the application on your computer or mobile phone:

### 1. Clone the repository
```bash
git clone https://github.com/Arafat-boss/Todo-List-Application.git
cd Todo-List-Application
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the app
```bash
npx expo start
```

---

## 📱 Viewing on Your Device

- **On Mobile Phone (Recommended):**
  1. Install the **Expo Go** app from the Google Play Store or Apple App Store.
  2. Make sure your computer and phone are connected to the same Wi-Fi.
  3. Scan the QR code shown in your terminal using the Expo Go app (Android) or Camera app (iOS).

- **On Web Browser:**
  - Press `w` in the terminal, or open [http://localhost:8081](http://localhost:8081) directly in your browser.

- **On Android Emulator:**
  - Press `a` in the terminal with an active Android emulator.
