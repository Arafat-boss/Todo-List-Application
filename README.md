# Todo List Application 📱

A modern React Native & Expo mobile application built with Expo Router.

## 🚀 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm start
```
*(or `npx expo start`)*

### 3. Run on your platform of choice

- **Web:** Press `w` or run `npm run web` (runs on http://localhost:8081)
- **Mobile (Expo Go):** Open the Expo Go app on your phone and scan the QR code.
- **Android Emulator:** Press `a` or run `npm run android`
- **iOS Simulator:** Press `i` or run `npm run ios`

## 🛠️ Built With

- **Expo SDK 58**
- **React Native 0.88**
- **React 19**
- **Expo Router** (File-based navigation)
- **TypeScript**
